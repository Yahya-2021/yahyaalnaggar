# Professor Yahya Al Naggar — Academic Website

A responsive, single-page academic portfolio built with plain HTML, CSS, and JavaScript. It is designed for free hosting on GitHub Pages.

## Files
- `index.html` — website content and page structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and dynamic footer year

## Before publishing: personal details to verify
Please review these items in `index.html` before making the site public:
1. Confirm the academic title and appointment dates.
2. Replace the general Google Scholar, Scopus, ORCID, and LinkedIn destinations with your exact personal profile URLs.
3. Confirm the email address shown in the contact section.
4. Add your preferred professional portrait if desired. The current hero artwork is an abstract, editable CSS illustration and does not use a stock portrait.
5. Expand the publications section with your selected papers and DOI links. The current version features the 2026 Nature paper and links to researcher platforms.

## Publish with GitHub Pages (free)
1. Sign in to GitHub and create a new **public** repository named `your-github-username.github.io` (replace with your actual GitHub username).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root. You may also upload this README.
3. Open the repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes. Your site will be available at `https://your-github-username.github.io/`.

If you use a repository with another name, such as `academic-website`, the address will usually be `https://your-github-username.github.io/academic-website/`.

## Editing
You can edit the HTML directly on GitHub, or locally in any code editor. Every section is labeled with an HTML comment-free semantic section ID to make it easy to find. Update text and links in `index.html`; adjust colors and layout variables at the top of `styles.css`.
